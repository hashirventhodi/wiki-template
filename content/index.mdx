## Using this template

1. Search-replace `PROJECT_NAME` and `Project` / `Project Wiki` across `content/` and `app/layout.tsx`.
2. Update branding (`SITE_NAME`, `ORG_NAME`, `REPO_URL`) in `app/layout.tsx`.
3. Replace each stub page under `content/` with real content. Keep the domain folders you need; delete the rest (remember to update the parent `_meta.ts`).
4. Read the [Style Guide](/operations/style-guide) before writing — it captures the voice and the MDX/Mermaid gotchas.
5. Delete this "Using this template" section once you're underway.
